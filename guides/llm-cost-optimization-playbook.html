1. Put Static Context First to Unlock 75–90% Prompt Caching

Every modern frontier API (Anthropic, OpenAI, Google Gemini, DeepSeek) bills cached prompt prefixes at 10% to 25% of base input cost. Never inject dynamic timestamps, request UUIDs, or per-user metadata at the top of your system prompt—put immutable instructions, JSON tool schemas, and few-shot examples first so prefix hit rates cross 70–90%.

2. Implement a 70/30 Model Cascade Router

Sending every customer inquiry or classification task to a flagship reasoning model wastes 5x–15x budget. Use a fast classifier or rule gate on a mini/flash model ($0.10–$0.30/1M) to handle 70% of routine requests and escalate only complex reasoning to GPT-5 or Claude Sonnet/Opus.

3. Minify Tool Schemas and System Prompts

Pretty-printed JSON tool definitions with verbose descriptions routinely burn 1,500–4,000 input tokens on every single turn. Running whitespace minification and concise parameter descriptions cuts recurring spend permanently—test your exact savings in our Token Inspector.

4. Move Non-Interactive Jobs to 50% Batch APIs

Nightly summarization, eval suites, document enrichment, and SEO classification rarely need 2-second latency. Moving offline queues to OpenAI, Anthropic, or Gemini Batch endpoints cuts both input and output rates by 50% immediately.
