The Hidden Upfront Tax of Connected MCP Servers

Every MCP server you connect injects JSON tool names, verbose descriptions, and nested parameter schemas into the system context on every single turn. Five servers with 14 tools each easily consume 15,000 to 22,000 tokens before the user types a single word.

Why Lazy Tool Deferral Beats Always-On Schemas

Sending only a compact 14-token name/summary index upfront and loading full JSON schemas on demand trims 80–90% of recurring schema tokens while also improving tool-selection accuracy.
