Frequently Asked Questions

Does TokenLedger send my pasted prompts to any server?

Never. All token estimation, pricing calculations, CSV/JSON exports, and JSON minification run 100% locally inside your browser with zero network transmission of prompt text.

How does LLM prompt caching affect monthly API cost?

Major providers discount repeated prompt prefixes by 75% to 90%. For high-volume apps with stable system prompts or tool schemas, prompt caching often cuts total input spend by more than half.
