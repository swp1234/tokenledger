When is self-hosting an H100 GPU cheaper than using a Cloud LLM API?

Self-hosting typically breaks even once steady daily request volume exceeds several thousand requests per day (often 3,000–15,000+ depending on output length and prompt caching) and GPU utilization stays above 25–35%.
